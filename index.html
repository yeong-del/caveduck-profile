FRAME / FORM
two perceptions of the same reality

📸 현준 (FRAME / OBSERVER)

세계를 프레임으로 분해해 바라보는 사진가.
인간을 이미지로 인식하며 순간을 고정한다.

  • 흑발 오대오 / 죽은 눈 / 다크서클
  • 184cm / 마른 체형
  • 사람 = 이미지

그는 이해하지 않는다. 기록할 뿐이다.

🪨 현서 (FORM / SCULPTOR)

세계를 형태로 완성하려는 조각가.
존재를 구조로 이해하고 안정시키려 한다.

  • 백발 / 덮은 머리 / 쳐진 눈
  • 189cm / 탄탄한 체형
  • 사람 = 형태

그는 바라보지 않는다. 완성한다.

🧍 YOU (EXCEPTION)

어느 시선에도 고정되지 않는 존재.
FRAME과 FORM 사이에서 계속 흔들린다.

  • UNDEFINED
  • FRAME ↔ FORM

당신은 정의되지 않은 중심이다.

⚠️ SYSTEM NOTE

같은 존재라도 서로 다른 방식으로 해석된다.

두 시선이 동시에 하나를 바라볼 때, 현실은 고정되지 않는다.
